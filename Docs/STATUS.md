# 개발 진행사항

2026-09-24 기준 로컬 작업 트리와 저장소 문서를 살펴본 요약입니다. 아래의 “구현”은 관련 코드·에셋이 존재한다는 뜻이며, 출시 품질 검증 완료를 뜻하지 않습니다. 상세 작업과 완료 조건은 [로드맵](Roadmap/README.md)에 있습니다.

| 영역 | 현재 상태 |
|---|---|
| 도시 기본 루프 | 도로·구역·필지, 성장, 인구·일자리, 전력, RCI 수요와 월간 재정 구현 |
| 도시 운영 | 저장·불러오기, 도로 업그레이드·일방통행, 집계 교통·버스, 쇠퇴·재개발, 서비스·수도·밀도·지구 정책 구현 |
| 화면과 조작 | 아이소메트릭 카메라, 건설·선택·오버레이, HUD·설정·출시 메뉴 구현. UI와 도시 아트 개선 진행 중 |
| 성능과 출시 | 벤치마크·빌드·저장 호환 검증 도구가 있으나, 동일 커밋의 Windows/macOS 출시 후보 검증은 미완료 |

## 지금 진행 중

- 한국 도시 분위기의 건물·도로·차량·환경 에셋과 UI, 조명·표면 품질을 다듬고 있습니다. 구현 및 검증 범위는 [P9 아트](Roadmap/P9-release/P9-01-production-art-pipeline.md)와 [P9 UI](Roadmap/P9-release/P9-02a-onboarding-release-ui.md)에 기록합니다.
- 첫 15분 플레이에서 건설부터 성장과 문제 해결까지 이해할 수 있는지 실제 화면으로 검증해야 합니다.
- Windows/macOS의 깨끗한 체크아웃에서 같은 커밋으로 빌드·회귀 테스트·성능 측정·저장 호환·에셋 라이선스 감사를 마쳐야 합니다. [출시 후보 체크리스트](Release/P9-RC-EVIDENCE-CHECKLIST.md)는 아직 완료되지 않았습니다.

## 확인된 검증과 한계

**2026-09-24** 현재 변경을 macOS의 Unity 6000.5.3f1에서 검사한 결과 EditMode 380개 통과·Windows 전용 1개 제외, PlayMode 59개 통과였습니다. 이 테스트는 개발 작업 트리에서 실행했으며 깨끗한 체크아웃의 출시 빌드 검증을 대신하지 않습니다. 이전 개발용 Standalone 실행 기록은 [P9 UI 기록](Roadmap/P9-release/P9-02a-onboarding-release-ui.md)에 있습니다. Windows 출시 빌드 및 양 플랫폼 출시 후보 승인은 아직 기록되지 않았습니다.

현재 코드와 이 문서 사이에 차이가 생기면 실행 결과와 해당 로드맵 이슈의 최신 증거를 우선합니다.
